# KINETIX — Minimalist Fitness & Physiological Hub

Built from the Stitch project `3360197600215191035` implementing both Stitch Design Systems (**Kinetic Minimal** Dark Mode and **Kinetix Clinical Performance** Light Mode) and all 4 primary screens.

## Running Locally

```bash
npm.cmd install
npm.cmd run dev
```

Open http://localhost:5173 in your browser.
